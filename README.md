# PharmaFlowMVC

**PharmaFlowMVC** est un projet d’application web de gestion de pharmacie, développé avec **C# et ASP.NET Core MVC**.

## 🎯 Objectif du projet

Créer une interface web permettant de poser les bases d’un système de gestion de pharmacie, avec une interface claire, moderne et facile à utiliser.

## 🛠️ Technologies utilisées

- **C#** — langage de programmation
- **ASP.NET Core MVC** — framework web
- **Razor** — création des vues dynamiques
- **HTML / CSS** — structure et présentation de l’interface
- **.NET 10** — plateforme de développement

## 📌 Fonctionnalités actuelles

- Tableau de bord de présentation
- Structure de projet ASP.NET Core MVC
- Organisation du code avec les contrôleurs, les modèles et les vues

## 🚧 État du développement

Le projet est en cours de développement. Les fonctionnalités de gestion des produits, des stocks et des autres opérations de pharmacie pourront être ajoutées progressivement.

## ▶️ Exécuter le projet en local

### Prérequis

- Installer le SDK .NET 10
- Installer Visual Studio ou Visual Studio Code

### Instructions

1. Cloner le dépôt GitHub.
2. Ouvrir un terminal dans le dossier `PharmaFlowMVC`.
3. Exécuter les commandes suivantes :

```bash
dotnet restore
dotnet run
```

4. Ouvrir dans le navigateur l’adresse locale affichée dans le terminal.

## 👩‍💻 À propos
